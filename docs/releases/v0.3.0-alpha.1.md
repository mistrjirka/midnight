## Blind solving with automatic annotated results

No RA, Dec, focal length or field-of-view hint is required. The solver searches a generic HYG sky index and verifies additional catalog stars before accepting a result.

- **Solve LiveView (3s)** now opens a frozen copy of the captured frame with coordinates, boxes and star names automatically. Q returns to Midnight. The three-second delay is stabilization, not a long exposure.
- **Solve image file** automatically opens the same annotated result screen.
- Gallery **Play -> Q -> SET** remains implemented but its native Canon album/RAW decoding path is not validated end to end.
- The full firmware ZIP includes SKY.DIR, SKY.PAT, SKY.FLD and STARS.NAM. Extract the entire matching ZIP. Old BLQ/BIX/BKX files are not needed.
- Retains the ARM size-optimized build. Immediate geometric verification avoids the old multi-minute vote search.
- Packaging verifies that astro.mo is the freshly compiled module, not a stale copy from the platform ZIP.

## Camera-emulator evidence

Both original photo-derived frames passed again in Canon EOS 600D firmware 1.0.2 running in QEMU, using the rebuilt source: **IMG_7975: 30 stars, RA 80.1032 deg, Dec +33.8599 deg; IMG_6446 with a bright trail: 14 stars, RA 327.9574 deg, Dec +47.5273 deg.** A blank frame is rejected without coordinates.

Earlier repeat runs recorded 434 ms and 836 ms. The pre-publication rerun recorded 420 ms and 846 ms. These are QEMU firmware timer readings, not physical-camera speed estimates. Conversion from the original CR2 embedded JPEG to 360x240 grayscale happens before the emulator test. All detection, solving, name lookup and rendering run in the compiled camera firmware. The attached screenshots are actual QEMU LCD captures from the earlier verified run, not mockups.

## Experimental, not hardware validated

**600D 1.0.2:** image-file solve and annotation rendering tested in QEMU. The new automatic Live View preview routing is built from the same renderer, but real sensor input has not been tested. **6D 1.1.6:** compile-tested only. Physical cameras, SD timing, and autofocus motors remain unverified. No physical-camera safety or performance validation is claimed.

Use a spare SD card and keep a known-working card. Electronic autofocus can move the lens. Do not install a package for a different model or Canon firmware version. ROM dumps and original photographs are not included.
