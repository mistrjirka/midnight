# Midnight v0.5.0-alpha.1: nine Canon EOS cameras

**Experimental prerelease.** Adds five camera builds: **650D, 100D, 60D,
1100D and 70D**, while retaining 550D, 600D, 700D and 6D.

Matching `magiclantern-astro-<camera>.<version>.zip` files are also attached
for fresh, compatible Magic Lantern cards. Each full ZIP contains camera-
specific `autoexec.bin`. **Do not put a full ZIP for one camera on another.**
The module-only ZIP preserves your working boot files, photos and settings.

## Controls

- **Gallery solve:** show a full-screen photo, then press **Q → SET**.
- **100D:** press **Av / exposure compensation** instead of Q, then SET.
  Magic Lantern uses Av as the separate Q action on this model.
- **Live View solve:** use **1× photo Live View**, not movie mode or 5×/10×.
- **Focus shortcut:** Off by default on the new cameras. Optional manual
  INFO or double half-press remains available. Only 600D and 6D have a
  dedicated default special-button mapping.
- Touch input remains with Canon. It never triggers solving automatically.

## Validation and limits

The module uses one portable plate solver and camera-specific firmware
checks, sensor dimensions and key translation. All nine camera images are
built against the pinned Magic Lantern platform. The automated build checks
that all module imports exist in each camera's exported firmware symbols.

Host tests validate camera/firmware gates, gallery button callbacks,
Live View zoom checks, the portable solver and each platform's real Magic
Lantern button translator. ZIP contents and matching boot files are verified.

The five new camera ports **have no physical-camera test evidence yet**.
The 100D and 70D use a constrained memory-allocation region, and the 1100D
also needs runtime memory testing. Live View capture, gallery UI, touch
events, and electronic focus motors require checks on real cameras.
The existing 550D and 700D ports also remain experimental.
