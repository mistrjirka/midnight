# Midnight v0.4.0-alpha.1: modular astronomy build

**Experimental prerelease.** Supports **Canon EOS 600D firmware 1.0.2** and **Canon EOS 6D firmware 1.1.6**. The physical-camera Live View, photo-gallery, polar alignment, and autofocus workflows remain unverified. Keep a backup of your working SD card and test on a spare card if possible.

## Changes

- Refactored Midnight into separate camera-integration and portable C astronomy components, building on [kubakubakuba/AstroML](https://github.com/kubakubakuba/AstroML), while keeping the Midnight name and **Focus → Midnight** menu.
- Added two-photo polar alignment, GPS/EXIF location reading, and improved polar sky-index coverage.
- Improved display image sampling: average neighbouring YUV pixels rather than selecting a single pixel.
- Fixed the **Play → Q → SET** gallery confirmation state machine to prevent unrelated key events from dismissing the prompt and triggering Canon's unrelated *Scrollwheel: Exposure Adjust* action. Failures remain visible in the gallery.
- Added Live View preflight and specific reasons for cancellation. **Live View at 5× or 10× remains unsupported.** The repair is tested in simulation, not yet proven on a physical camera.
- Preserved legacy Midnight settings, the original intervalometer and Bulb Timer links, and added module-only installation packages.

## Downloads

| Camera | Existing compatible Magic Lantern card (recommended) | Full Magic Lantern installation |
| --- | --- | --- |
| Canon EOS 600D, firmware 1.0.2 | `midnight-module-600D.102.zip` | `magiclantern-astro-600D.102.zip` |
| Canon EOS 6D, firmware 1.1.6 | `midnight-module-6D.116.zip` | `magiclantern-astro-6D.116.zip` |

The module-only ZIP contains `ML/modules/astro.mo` and `ML/ASTRO` databases. It **does not replace `autoexec.bin`**, Canon firmware, boot flags, or photographs. Extract to the card root. Back up the existing `ML/modules/astro.mo`, `ML/ASTRO`, and settings first. Enable the module if necessary, then restart.

The optional `magiclantern-astro-wide-index.zip` extends support for wider fields. The full ZIP is for a fresh or specifically verified compatible Magic Lantern installation, **not** a routine update over an existing working card.

## Validation

- **53** regular host tests passed, **10** additional long solver tests passed; **2** tests skipped because the original private CR2 files are not available. Portable C tests include regression comparisons against the earlier Midnight algorithms.
- The same ARM module compiled against **600D.102** and **6D.116**, with **zero missing imports across 81 required symbols**.
- Canon 600D QEMU launched the modular Midnight menu and solved a bundled synthetic test field with **11 star matches**; 0.19 seconds of emulated solver time. Labels, coordinates, and a target arrow rendered on the LCD.
- Simulated playback button handling and YUV downsampling passed.
- **Not yet established:** actual 600D gallery decoding, real sensor Live View solving, physical focus motor safety, and polar alignment accuracy on a mount. Do not use the latter for unattended motorized movement.

Source review and testing details: [Modular migration review](https://github.com/mistrjirka/midnight/blob/v0.4.0-alpha.1/docs/MODULAR_MIGRATION.md).
