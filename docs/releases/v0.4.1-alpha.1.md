# Midnight v0.4.1-alpha.1: Canon 550D and 700D support

**Experimental prerelease.** Adds camera-specific Magic Lantern builds for **Canon EOS 550D firmware 1.0.9** and **Canon EOS 700D firmware 1.1.5**, alongside **600D firmware 1.0.2** and **6D firmware 1.1.6**.

**550D and 700D have not been tested on physical cameras.** The 600D is reported working by the project user. Compilation and QEMU tests cannot establish physical compatibility with new models. Keep a backup and use a spare SD card.

## Downloads

| Camera / Canon firmware | Existing matching Magic Lantern card (recommended) | Full experimental Magic Lantern files |
| --- | --- | --- |
| **550D 1.0.9** | `midnight-module-550D.109.zip` | `magiclantern-astro-550D.109.zip` |
| **600D 1.0.2** | `midnight-module-600D.102.zip` | `magiclantern-astro-600D.102.zip` |
| **700D 1.1.5** | `midnight-module-700D.115.zip` | `magiclantern-astro-700D.115.zip` |
| **6D 1.1.6** | `midnight-module-6D.116.zip` | `magiclantern-astro-6D.116.zip` |

The **module-only ZIP** contains `ML/modules/astro.mo`, the module-enable flag and matching `ML/ASTRO/` sky data. It **does not** replace `autoexec.bin`, `ML-SETUP.FIR`, saved camera settings, photos, or the card boot flags. Use it only if Magic Lantern already works on the specified camera and firmware revision.

The **full ZIP** includes camera-specific boot files. Use it only on a suitable spare card with the exact Canon firmware revision. Do **not** install a ZIP for a different camera.

## Button mappings reviewed

The actual pinned Magic Lantern `gui.h` and `module_translate_key()` code were checked for all four models. Host regressions compile Magic Lantern's **actual key-translator C function**, and verify Q, SET press/release, PLAY, INFO, Delete, arrow, and shutter half-press/release. They also check the 700D touchscreen events are **not mapped to Q or SET**.

| Button | 550D | 600D | 700D | 6D |
| --- | --- | --- | --- | --- |
| Raw **Q** | `0x0F` | `0x13` | `0x1D` | `0x1D` |
| Raw **SET** | `0x04` | `0x04` | `0x04` | `0x04` |
| Raw **PLAY** | `0x09` | `0x0B` | `0x0B` | `0x0B` |
| Raw **INFO** | `0x07` | `0x07` | `0x07` | `0x07` |

The **550D/700D start with the special autofocus shortcut Off**. The previous 600D DISP / 6D LCD-light shortcut remains supported only on those cameras. Manual INFO or double half-press modes remain optional.

## Validation

- Four platform-specific ARM builds and the portable solver compile from the same pinned Magic Lantern source.
- The build checks every module import against **550D_109**, **600D_102**, **700D_115**, and **6D_116** firmware symbol tables.
- Button-map and camera-gate tests, gallery Q -> SET state machine, and Live View 1x/zoom tests run with the regression suite.
- All release ZIPs are verified to contain their matching module and sky data. Module-only ZIPs exclude boot files; full ZIPs contain the correct camera-specific `autoexec.bin`.
- The 550D has a small memory allocation pool. Midnight needs roughly **630 KiB** in combined working buffers during a solve before system overhead. RAM headroom on the physical 550D is unknown.
- Physical gallery preview capture, Live View YUV buffers, touchscreen presentation on 700D, actual AF motors, and polar alignment are not established on either new camera.

See [installation and rollback](https://github.com/mistrjirka/midnight/blob/v0.4.1-alpha.1/docs/INSTALL.md), [550D caveats](https://github.com/mistrjirka/midnight/blob/v0.4.1-alpha.1/docs/550D_PORT.md), and [700D caveats](https://github.com/mistrjirka/midnight/blob/v0.4.1-alpha.1/docs/700D_PORT.md).

No changes to the earlier release tags or installed SD cards.
